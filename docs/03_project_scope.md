# Project Scope

## Purpose

This portfolio case study evaluates how publicly observable service-demand
indicators, document-quality issues, process design, and the transition to ARLO
could affect Alberta Land Titles service performance.

The analysis is based exclusively on publicly available information and does
not represent an internal Government of Alberta assessment.

## In Scope

- Historical Land Titles processing-time performance
- Publicly reported document-registration volumes
- Document deficiencies and resulting rework
- Pending Registration Queue processes
- Current-state document-registration workflow
- ARLO modernization and transition impacts
- Alberta population and housing-market indicators
- Edmonton and Calgary property/development activity
- Demand-pressure analysis using public proxy datasets
- Business-process improvement opportunities
- Business and functional requirements
- Service-performance KPIs
- Power BI operational dashboard prototype
- Demand-pressure forecasting
- UAT scenarios
- Implementation, risk and change-management planning

## Out of Scope

- Individual Land Titles transaction records
- Internal staffing levels or employee productivity
- Internal ARLO system architecture
- Proprietary Government of Alberta databases
- Actual ARLO source code or configuration
- Production cybersecurity testing
- Legal interpretation of Land Titles legislation
- Actual implementation of system changes
- Claims that proxy indicators represent exact Land Titles transaction demand

## Geographic Scope

Primary analysis:
- Alberta

Additional geographic analysis:
- Edmonton
- Calgary

Municipal data will be used as indicators of property-market and development
activity and will not be treated as direct Land Titles workload data.

## Time Horizon

Historical analysis:
Approximately 2021–2026, depending on dataset availability.

Forward-looking analysis:
Scenario modelling for future service-demand pressure.

## Primary Deliverable

An independent Business Services Analyst case study demonstrating:

business analysis → data analysis → process improvement → requirements →
solution options → testing → implementation planning.
